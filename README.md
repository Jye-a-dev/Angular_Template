# Angular Production-Ready Template (`angular_template`)

A modern, production-grade Angular enterprise starter template optimized for high-performance solo and team engineering workflows.

---

## Tech Stack & Versions

- **Angular Core & CLI:** `v22.3.0` (Zoneless, Standalone Components, Modern Control Flow, Signals)
- **TypeScript:** `~6.0.2` (Strict mode enabled, direct path aliases)
- **Styling:** Tailwind CSS `v4.3.5` via `@tailwindcss/postcss` & `postcss`
- **Icons & UI Helpers:** `@lucide/angular` / `lucide-angular`, `clsx`, `tailwind-merge`
- **Validation:** `zod` (`v4.6.7`) for environment variables and domain schemas
- **Code Quality:** `eslint` (`v9+`), `angular-eslint` (`v22.8.0`), `eslint-config-prettier`
- **Formatting:** `prettier` (`v3.10.1`), `prettier-plugin-tailwindcss`
- **Git Hooks:** `husky` (`v9.1.7`), `lint-staged`, `@commitlint/cli`, `@commitlint/config-conventional`

---

## Prerequisites

- **Node.js:** `>= 22.0.0` (Matches `.nvmrc`)
- **Package Manager:** `npm >= 11.0.0`

## Quick Start

1. **Clone repository:**

   ```bash
   git clone <repository-url>
   cd angular_template
   ```

2. **Setup environment:**

   ```bash
   cp .env.example .env
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Launch development server:**

   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5000`.

## Environment Variables

Controlled via `.env` at root (ignored by Git, seeded from `.env.example`):

| Variable          | Default Value               | Description                                                                |
| :---------------- | :-------------------------- | :------------------------------------------------------------------------- |
| `NG_PORT`         | `5000`                      | Port for the Angular development server                                    |
| `NG_API_BASE_URL` | `http://localhost:8000/api` | Base URL synchronized into `environment.ts` & `environment.development.ts` |

## Project Structure

```plaintext
src/
├── app/
│   ├── core/                         # Singletons, security, network & env validation
│   │   ├── config/
│   │   │   └── env.ts                # Zod runtime validation for environment variables
│   │   ├── guards/
│   │   │   └── auth.guard.ts         # Functional CanActivateFn guard
│   │   └── interceptors/
│   │       └── api.interceptor.ts    # Functional HttpInterceptorFn (baseUrl & auth)
│   ├── features/                     # Domain modules (team-friendly feature isolation)
│   │   └── example/
│   │       ├── components/           # Feature-specific UI components
│   │       ├── models/               # Domain interfaces & TypeScript types
│   │       ├── schemas/              # Zod validation schemas
│   │       ├── services/             # Signal-based domain state & API logic
│   │       ├── example.component.ts  # Feature page component
│   │       └── example.routes.ts     # Lazy-loaded feature routes
│   ├── layouts/
│   │   └── main-layout.component.ts  # Application shell & navigation layout
│   ├── shared/                       # Cross-cutting reusable artifacts
│   │   ├── components/               # Generic UI primitives (app-button, etc.)
│   │   ├── directives/               # Shared directives (highlight, etc.)
│   │   ├── pipes/                    # Shared pipes (truncate, etc.)
│   │   └── utils/
│   │       └── cn.ts                 # Class merger (clsx + tailwind-merge)
│   ├── app.config.ts                 # App-level providers (Zoneless, Router, HttpClient)
│   ├── app.html                      # Minimal root template (<router-outlet />)
│   ├── app.routes.ts                 # Root routes with lazy-loading
│   └── app.ts                        # Root AppComponent
├── environments/                     # Auto-generated by scripts/sync-env.mjs
│   ├── environment.development.ts
│   └── environment.ts
├── main.ts                           # Application bootstrap entrypoint
└── styles.css                        # Global styles & Tailwind CSS v4 import
```

### Architectural Division Rules

- **`src/app/core/`**: Put services that must be singletons, HTTP interceptors, global route guards, and typed environment configurations here.
- **`src/app/features/`**: Group all business logic by feature/domain. Each team or developer works independently in their feature folder with isolated routes, components, and signal services.
- **`src/app/layouts/`**: Shell templates, sidebars, headers, and navigation wrappers housing `<router-outlet />`.
- **`src/app/shared/`**: Generic, dumb UI primitives (buttons, inputs, modals), reusable pipes, directives, and utility functions that contain zero business logic.

## Available NPM Scripts

| Command              | Description                                                                                   |
| :------------------- | :-------------------------------------------------------------------------------------------- |
| `npm run dev`        | Runs `scripts/dev.mjs`: synchronizes `.env` and starts dev server on `NG_PORT` (default 5000) |
| `npm start`          | Alias for `npm run dev`                                                                       |
| `npm run build`      | Runs `scripts/sync-env.mjs` and executes production build (`ng build`)                        |
| `npm run type-check` | Runs TypeScript compiler checks without emitting files (`tsc --noEmit`)                       |
| `npm run lint`       | Runs Angular ESLint linter across all `.ts` and `.html` files (`ng lint`)                     |
| `npm run format`     | Runs Prettier across the entire codebase (`prettier --write .`)                               |
| `npm test`           | Runs unit tests (`ng test`)                                                                   |

## Git Commit Conventions

This project enforces [Conventional Commits](https://www.conventionalcommits.org/) using Husky and Commitlint:

```bash
git commit -m "feat(auth): implement token refresh interceptor"
git commit -m "fix(router): resolve redirect loop on 404 route"
```

Allowed types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.
